תקן ישראלי IS 5568

אתר זה נבנה בהתאם לדרישות התקן הישראלי IS 5568, המבוסס על הנחיות הנגישות לתכני אינטרנט WCAG 2.0 ברמת AA. תקן IS 5568 הוא תקן הנגישות הרשמי של מדינת ישראל בהתאם לחוק שוויון זכויות לאנשים עם מוגבלות.

רמת התאמה

סטטוס: תואם חלקית לתקן IS 5568 (WCAG 2.0 רמה AA).

הערכת הנגישות האחרונה בוצעה בתאריך 30/03/2026.

מה עשינו כדי להנגיש את האתר

האתר תוכנן ונבנה מהיסוד עם דגש על נגישות מלאה. אמצעי הנגישות שהוטמעו באתר:

  • תמונות: לכל תמונה באתר טקסט חלופי (alt) מתאר. תמונות דקורטיביות מסומנות כך שקוראי מסך מתעלמים מהן.
  • ניגודיות צבעים: יחס ניגודיות של לפחות 4.5:1 לטקסט רגיל ו-3:1 לטקסט גדול, בהתאם לדרישות WCAG AA.
  • ניווט מקלדת: ניתן לנווט בכל האתר באמצעות מקלדת בלבד (Tab, Enter, רווח). כל האלמנטים האינטראקטיביים נגישים למקלדת.
  • מבנה כותרות: האתר משתמש במבנה כותרות הגיוני (H1 → H2) ללא דילוג על רמות.
  • טפסים: כל שדות הטופס מלווים בתוויות (labels) מקושרות כראוי.
  • קישור דילוג: קישור "דלג לתוכן הראשי" מופיע בתחילת כל עמוד עבור משתמשי מקלדת וקוראי מסך.
  • מחווני פוקוס: כל האלמנטים האינטראקטיביים מציגים מחוון פוקוס ברור ונראה.
  • הגדלת טקסט: ניתן להגדיל את הטקסט עד 200% מבלי לאבד תוכן או פונקציונליות.
  • תאימות RTL: האתר בנוי מימין לשמאל בהתאם לשפה העברית.

אנו פועלים באופן מתמשך לשפר את נגישות האתר. מגבלות ידועות כרגע:

  • אנימציות הגלים בין הסקשנים הן דקורטיביות בלבד ומוסתרות מטכנולוגיות מסייעות.

Accessibility Statement

This statement applies to the website Chocoladot – Irit Shimoni.

Israeli Standard IS 5568

This website was built in compliance with Israeli Standard IS 5568, based on the Web Content Accessibility Guidelines (WCAG) 2.0 Level AA. IS 5568 is the official Israeli web accessibility standard mandated under the Equal Rights for Persons with Disabilities Law.

Conformance Level

Status: Partially compliant with IS 5568 (WCAG 2.0 Level AA).

Our most recent accessibility evaluation was conducted on 30/03/2026.

Accessibility Measures Implemented

This website was designed and built from the ground up with accessibility in mind. The following measures have been implemented:

  • Images: All images have descriptive alt text. Decorative images are hidden from screen readers.
  • Color contrast: Minimum 4.5:1 ratio for normal text and 3:1 for large text, per WCAG AA requirements.
  • Keyboard navigation: The entire site can be navigated using a keyboard only (Tab, Enter, Space). All interactive elements are keyboard accessible.
  • Heading structure: Logical heading hierarchy (H1 → H2) with no skipped levels.
  • Forms: All form fields have properly associated labels.
  • Skip link: A "skip to main content" link appears at the beginning of each page for keyboard and screen reader users.
  • Focus indicators: All interactive elements display a clearly visible focus indicator.
  • Text resizing: Text can be enlarged up to 200% without loss of content or functionality.
  • RTL compatibility: The site is built right-to-left to match the Hebrew language.

Assistive Technology Compatibility

This website is designed to work with the following assistive technologies:

  • Screen readers: NVDA (Windows), JAWS (Windows), VoiceOver (macOS/iOS)
  • Screen magnification: Magnification (Android), Magnifier (Windows), Zoom (macOS/iOS)
  • Voice control: Dragon NaturallySpeaking (Windows/Mac)
  • Mobile accessibility: AssistiveTouch (iOS), TalkBack (Android)

Known Limitations

We are continuously working to improve accessibility. Currently known limitations:

  • The image gallery in the workshop section may not be fully accessible to screen readers.
  • Wave animations between sections are decorative only and hidden from assistive technologies.

We are working to address these issues and will update this statement accordingly.
